# The Backstage Marketing Website

A responsive one-page agency website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Inquiry form
The form is configured with FormSubmit and sends inquiries to:
`inquiry.tbm@protonmail.com`

The first test submission will trigger an activation email. Open the Proton Mail inbox and confirm it once. After activation, new submissions will arrive automatically.

## Publish free
Upload the folder to Netlify, Vercel, GitHub Pages or your web host.

## Customize
- Update text in `index.html`
- Adjust colors in the `:root` section of `styles.css`
- Replace images inside the `assets` folder
